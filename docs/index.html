About

Vue 3 Multi-Calendar Datepicker is independently maintained as a general-purpose datepicker. It began from a copied working tree inspired by the original Persian datepicker project, but the current codebase has been substantially redesigned and extended.

The project is developed with AI-assisted exploration, coding, testing, and review. Contributions and careful human review remain welcome and important.

Basic usage

<script setup lang="ts">
import { ref } from 'vue';
import DatePicker from '@h-sanadgol/vue3-multi-calendar-datepicker';

const date = ref('1404/01/15');
</script>

<template>
  <DatePicker
    v-model="date"
    calendar="jalali"
    locale="fa"
    mode="single"
    clearable
  />
</template>

Calendar and language are independent. For example, a Jalali calendar can use English labels with calendar="jalali" locale="en".

Common props

Prop Values Purpose
type date, time, datetime Choose the value type.
mode single, range Choose a single value or start/end range.
locale fa, en, ar, he, th, zh Set the UI language.
hijri-provider ummalqura, tabular Choose the Hijri calculation method.
model-calendar Any supported calendar or active Choose the calendar used to serialize v-model.
from, to Calendar-formatted strings Limit the selectable range.
week-starts-on, weekend-days Weekday numbers Configure the week layout and weekly holidays.
minute-step, hour-step Positive numbers Control time increments.
color blue, red, green, etc. Choose a preset theme color.

See the full API and examples in the repository README.

Formats and input masks

The four format props have deliberately separate responsibilities. format serializes v-model; input-format controls the editable text field; display-format controls the readable label at the bottom of the open calendar; and input-mask controls what can be typed and whether separators are inserted.

Prop Example Effect
format jYYYY/jMM/jDD Serialized model string only.
input-format jYY/jMM/jDD Input display and manual parser.
display-format jD jMMMM jYYYY Readable footer label in the open picker.
input-mask { pattern: 'jYY/jMM/jDD' } Typing rules, separators, digits, and token ranges. 
<DatePicker
  v-model="date"
  calendar="jalali"
  format="jYYYY/jMM/jDD"
  input-format="jYY/jMM/jDD"
  display-format="jD jMMMM jYYYY"
  :input-mask="{
    pattern: 'jYY/jMM/jDD',
    autoInsert: true,
    strict: true,
    allowedDigits: 'both',
    blocks: {
      jYY: { from: 0, to: 99 },
      jMM: { from: 1, to: 12 },
      jDD: { from: 1, to: 31 },
    },
  }"
/>

Mask blocks without IMask

The object form is inspired by IMask's MaskedRange, but it is implemented internally and does not add IMask as a dependency. Use blocks to restrict each token while typing. 

<DatePicker
  v-model="dateTime"
  calendar="gregorian"
  type="datetime"
  input-format="YYYY/MM/DD HH:mm"
  :input-mask="{
    pattern: 'YYYY/MM/DD HH:mm',
    placeholder: 'YYYY/MM/DD HH:mm',
    autoInsert: true,
    strict: true,
    blocks: {
      YYYY: { from: 1970, to: 2030 },
      MM: { from: 1, to: 12 },
      DD: { from: 1, to: 31 },
      HH: { from: 0, to: 23 },
      mm: { from: 0, to: 59 },
    },
  }"
/>

With autoInsert, entering 050415 for jYY/jMM-jDD becomes 05/04-15. The complete value is committed on blur or Enter only when it passes the calendar's real date validation.

Token reminder: MM is month and mm is minute. Therefore YY-mm-DD is not a normal date format; use YY-MM-DD or YY-MM-DD HH:mm.

Behavior, ranges, and events

Bounds and time values

Date bounds use the active calendar. In time mode, use HH:mm bounds instead of date strings. 

<DatePicker
  v-model="time"
  type="time"
  from="08:00"
  to="18:00"
  minute-step="5"
/>

<DatePicker
  v-model="range"
  calendar="gregorian"
  mode="range"
  from="2020-01-01"
  to="2030-12-31"
  :week-starts-on="1"
  :weekend-days="[0, 6]"
/>

Behavior props

auto-submit commits complete selections immediately; clearable adds a clear action; click-on accepts all, input, icon, or none; modal changes presentation; show controls visibility; and dual-input renders separate range inputs. 

<DatePicker
  v-model="booking"
  mode="range"
  clearable
  dual-input
  icon-inside
  :auto-submit="false"
  label="Booking dates"
  color="purple"
/>

Events

Event When it fires
update:modelValue The committed model changes.
select A day, time, or range endpoint is selected.
submit The complete selection is submitted.
open / close The picker opens or closes.
clear The current value is cleared.

Advanced examples

Shortcuts

Set shortcut to true for built-in date/time actions. The object form supports labeled single values, ranges, times, and datetimes. 

<DatePicker v-model="date" shortcut />

<DatePicker
  v-model="range"
  mode="range"
  :shortcut="{
    Today: [today],
    'This week': [weekStart, weekEnd],
  }"
/>

<DatePicker
  v-model="appointment"
  type="datetime"
  :shortcut="{
    'Release time': ['2025-04-15 14:30'],
    'Office hours': ['09:00', '17:00'],
  }"
/>

Disable rules

Disable values with a string, array, regular expression, or function. The rule is evaluated using the active calendar and configured formats. 

<DatePicker v-model="date" disable="2025-04-15" />
<DatePicker v-model="date" :disable="['2025-04-15', '2025-04-20']" />
<DatePicker v-model="date" :disable="(value) => value.getDay() === 0" />

Locale and style customization

<DatePicker
  v-model="date"
  locale="en"
  :locale-config="{
    en: { today: 'Go to today', submit: 'Apply' },
  }"
  :styles="{
    primaryColor: '#7c3aed',
    borderRadius: '12px',
  }"
/>

Custom input slot

<DatePicker v-model="date">
  <template #input="{ value, inputAttrs, open, onInput, onBlur, onKeydown, clear }">
    <input
      v-bind="inputAttrs"
      :value="value"
      @focus="open"
      @input="onInput"
      @blur="onBlur"
      @keydown="onKeydown"
    />
    <button type="button" @click="clear">Clear</button>
  </template>
</DatePicker>
